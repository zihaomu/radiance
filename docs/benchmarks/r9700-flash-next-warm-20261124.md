# R9700 TP1 matched warm Qwen3.8-Flash-Next measurements

Measured 2026-11-24 on one physical Radeon AI PRO R9700 (GPU2, HIP ordinal 1). This report publishes **warm, single-stream server decode rates**. Each workload ran MTP0-A → MTP3-A → MTP3-B → MTP0-B, with an independent service start for every letter. Each start had 4–8 excluded warm-up requests, then **eight retained measured requests**. Warm-up ended only after three consecutive requests were within 5% and had no observed expert-prefetch state transition. All 12 starts and 96 measured requests completed without a foreign process on the selected GPU.

The code prompt asks for a Python `merge_intervals` implementation; the fixed 256-token response ends mid-function, so this is a **code continuation speed test**, not a completed coding-task quality score. The 32K archive uses the local archived prompt with SHA-256 `e7e3bd61ea7a2997a3791bba19ff56ead844ed47353a548ec12f2de9c89e87a6`. Prefix caching was disabled and all measured requests reported `cache_n=0`.

## Qualification and limitations

- The same-mode start median ratios were 1.011 / 1.017 (essay MTP0/MTP3), 1.003 / 1.003 (code) and 1.023 / **1.054** (archive). The archive MTP3 ratio corresponds to **5.416% drift**, exceeding the [original 5% gate](r9700-flash-next-warm-protocol.md). The user explicitly accepted this 5.4% variation for public display. Its 71.18 versus 71.46 tok/s difference is much smaller than the observed start drift; the result does **not** establish an MTP speed advantage or slowdown at 32K.
- All measured requests returned exactly 256 tokens, with the intended prompt count, no prefix hit and no observed prefetch transition during measurement. Every start had one output hash across its eight requests, and each mode's two starts agreed on that hash. MTP0 and MTP3 output hashes **differ** in all three workloads. Their rate ratios describe these deployment modes; they are not an equal-output, isolated MTP algorithm speedup.
- `predicted_per_second` is the server's decode rate, arithmetically equal to 255 generated-token intervals divided by `predicted_ms`. The requests were ordinary non-streaming HTTP calls, without a profiler. Client total wall time minus the server's TTFT gives a sanity-check rate within 0.17% of the server median in each start, but this is **not an independent client SSE timing check**. The planned independent SSE gate was not run; the public figures are explicitly server-reported.
- Source code was unchanged from Radiance `2a2b756371c26f2768b8d129a098df275ace2c73` apart from documentation on the fork's `main`. All cases used executable SHA-256 `8210861ca3dcea66d83a557a4c0f34f472af952a57a35c665ee7a9b4e6886763`, locked ROCm 10.1 image `sha256:81ecc42c4215f48f19da0afd96deff692ee6da6799c907a3172d5dbc967d4298`, and `qwen3.8-next-flash-iqr-v4.rad` revision `679c943216e5a33da5f458b5da378586219e874b`. The model's full SHA-256 `25aff8c950f4b823bc8b77c8184ed48827cb47058ffce08ae2c83b12e021fea0` came from a prior complete verification; this run rechecked the file size and unchanged mtime, not the full 121.7 GB hash.

TP1 kept the same requested resource settings across MTP modes: `max-num-seqs: 4`, `max-model-len: 200000`, `expert_tiered`, 43,000 MiB host pool, int8 KV, 4096 prefill tokens per batch and no prefix cache. Disabling MTP may still change effective memory placement; the result is a configuration comparison. The older **154.47 tok/s** TP1 essay result used physical GPU7 and a different warm-up history. This matched GPU2 run measured **149.40 tok/s**, about 3.3% lower; the older result remains in the [historical report](r9700-flash-next.md), rather than being combined with this cohort.

Local original requests, full outputs, all warm-up and measured rows, resource samples, service logs and lease release records are retained under `radiance_workspace/artifacts/flash-next-mtp-warm-20261124/{essay,code,archive}`. The linked JSON files above contain every measured rate, start median, warm-up count, output hash and audit decision. All experiment containers were stopped and the GPU2 reservation was released.
