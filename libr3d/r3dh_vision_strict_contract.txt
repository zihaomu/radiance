R3DH VISION STRICT DEVICE CONTRACT

Ownership: only new libr3d/r3dh_vision_strict* files. No shared CMake,
registry, architecture, existing kernel, commit or push changes.

Integration API (r3dh_vision_strict.h)
r3dh_vision_strict_kernels(int*) returns 15 RadKernelInfo rows, all DEVICE:
seven exact N/K rows for gemm_nt, seven for gemm_nt_bias, one attn_dense.
r3dh_vision_strict_schemas(int*) returns three RadOpSchema descriptors.
Copy returned descriptors into the owning plugin's tables; do not register
these as HOST kernels. Returned tables have static lifetime. No scratch,
initialization, relayout, tuning, host compute fallback or external BLAS.
r3dh_vision_strict_shape(op, params, count, operand, description) is the
common shape hook; row-specific RadShapeFn adapters are supplied.

gemm_nt(a,b,y), gemm_nt_bias(a,b,bias,res?,y)
Parameters: M,N,K integer, dtype=bf16; bias version act=none|gelu|gelu_tanh.
M range 1..256. N/K pairs and actual architecture calls:
1152/1536 patch, v.patch.weight [1152,3,2,16,16] flattened without reorder;
3456/1152 attention QKV, v.blk.L.qkv.weight [3456,1152];
1152/1152 attention output, v.blk.L.proj.weight [1152,1152], residual;
4304/1152 FF up, v.blk.L.fc1.weight [4304,1152], gelu_tanh;
1152/4304 FF down, v.blk.L.fc2.weight [1152,4304], residual;
4608/4608 merger FC1, v.merger.fc1.weight [4608,4608], exact gelu;
2560/4608 merger FC2, v.merger.fc2.weight [2560,4608].
All weights and biases plain BF16; matrices rank2 with positive row pitch
>= columns, unit inner stride. Bias rank1 [N], positive element stride.
Output BF16. FP32 sum starts at +0, K strictly ascending, separate multiply
and add, bias only after final K. Round BF16 RNE, then optional double-libm
GELU cast F32 and BF16 round, then residual add and BF16 round. Exact same
residual/output view is supported, partial overlap is rejected. Output may
not overlap a,b,bias. Every nonnull operand must be current-device HIP memory.

attn_dense(q,k,v,cu_seqlens,out)
BF16 q/k/v/out [M,1152] or [M,16,72], dimension contiguous, positive
nonoverlapping head/row pitches; fused QKV column views have row pitch3456.
cu_seqlens contiguous DEVICE I32 [S+1], starts0, endsM, monotone within [0,M];
empty segments allowed. Invalid boundaries safely leave output untouched;
they do not synchronously report a host error. Caller must supply valid CU.
M1..256; head_dim72, gqa1, causal0, window0, window_right0, block0, cu_div1.
scale finite F64 parameter cast F32, defaults 1.0f/sqrt(72.0f), matching
libref's FP32 default; rounding a double-precision reciprocal is not identical.
max_seqlen is an ignored capacity parameter, never permission to exceed M256.
Dots ascend dimension0..71. Two score passes with FP32 max, FP32 sum of
float(exp(double(score-max))), FP32 ascending-key value sums, BF16 RNE output.
No BF16 probability rounding, no head padding to128/256, no FMA contraction.
Output may not overlap q/k/v/cu. Strict scalar baseline, not a tuned kernel.

Explicit exclusions and integration gates
M>256 (audit uses2048 patches/512 merger rows), other N/K, F32 output,
quantized weights, causal/window/block/GQA attention and head128/256 are not
supported by this port. Parameter/stride/device guards remain authoritative.
This port does NOT provide grid_embed, layernorm, axial rope(head72,
sections18+18), scatter_rows, preprocessing/FFmpeg or separate conv3d_strided.
Grid width1152/side48 is now separately qualified by the MTP owner through
registered r3d_grid_embed_1152_s48_bf16, including exhaustive M2048 checks
with three changed inputs and guarded inputs/outputs/scratch. Evidence:
