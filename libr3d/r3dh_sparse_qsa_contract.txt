schema_at outside 0..3 returns null. schema_count returns 4.
Launch APIs validate descriptors and enqueue native HIP on the supplied stream;
RAD_OK is enqueue success, not completion. The caller synchronizes for errors.
No scratch or CPU/libref fallback is used by these four production kernels.

Operand mapping, zero-based; all runtime pointers are device pointers
qsa_block_key: 0 k BF16 [4B,128], 1 w F32 [128], 2 page I32 [B]
optional, 3 pos I32 [B], [B,1] or [B,3] optional, 4 out BF16 [P,128]
or [P,a,b,c] with contiguous a*b*c=128. Page absent means page=block.
Position absent requires pos0 and uses pos0+block*4. Negative/out-of-range
output page IDs leave the destination untouched. Pool four keys ascending,
round pool to BF16 RNE, double sum of squares, F32 RMSNorm and weight+wadd,
NeoX/M-RoPE/interleaved M-RoPE, final BF16 RNE. No fused contraction.
Required n=128, ratio=4; block_size=4, dtype=bf16. B=1..2048.
rotary_dim even 0..128; eps>0, theta>0, scale>0, finite wadd.
Modes neox/mrope/imrope. Explicit 3-coordinate M-RoPE sections must sum
to rotary_dim/2. Current geometry uses rotary_dim=64, sections=11 11 10.
Nonzero yarn_factor is refused. No YaRN extension is implemented.

qsa_score: 0 q BF16 [M,512], 1 bk BF16 [P,128] or page form above,
2 bt I32 [S,W], 3 cu I32 [S+1], 4 nc I32 [S], 5 score F32 [M,Wout].
n=128, heads=4, dtype=bf16. M=1..2048, S=1..2048, Wout<=50000.
Ascending 128-lane F32 dot for each head, ReLU each dot, ascending four-head
sum, divide by sqrtf(128). Invalid physical bk page writes negative infinity.
Columns beyond table width/nc and rows outside cu remain untouched.
bk page IDs and attention bt page IDs are separate physical namespaces.

qsa_select: 0 score F32 [M,W], 1 bt I32 [S,Wtable], 2 nc I32 [S],
3 pos I32 [M], 4 cu I32 [S+1], 5 sel I32 [M,topk+1],
6 nsel I32 [M], 7 seqused I32 [M]. M,S=1..2048, W<=50000,
ratio=4, topk=1..512, signed=0 or 1. Complete candidates are bounded by
nc, both widths and floor((pos+1)/4). Negative physical IDs are excluded.
Unsigned mode rejects values not greater than -1e30, then clamps negatives
to zero. Signed mode accepts finite values only and preserves negatives.
At most topk complete pages: values above threshold in source-column order,
then threshold ties in source-column order; not score-sorted output.
A valid partial page follows when (pos+1)%4!=0. Pad through topk with -1.
nsel counts pages; seqused=nsel ? (nsel-1)*4+pos%4+1 : 0.
A row not covered by cu uses sequence zero, matching libref.
Selection emits physical attention cache IDs, not logical index-block IDs.

attn_paged: 0 q BF16 [M,H*D] or [M,H,D], 1 kv_cache BF16 or I8
[P,Hkv,4,2D] or I8 [P,Hkv,4,2D+4], 2 block_table I32 [S,W],
3 seqused I32 [S], 4 k_descale absent, 5 v_descale absent,
6 cu_seqlens I32 [S+1] optional, 7 out BF16 shaped like q.
D=128 or 256, gqa=1..16, H=Hkv*gqa<=128; M,S=1..2048.
block_size=4, causal=1, window=0, q_dtype=bf16; matching kv_dtype.
I8 token row is signed K[D], signed V[D], little-endian FP16 K scale,
little-endian FP16 V scale. No external scale tensor or compressed layout.
Last tensor axis unit-stride; nonoverlapping padded outer pitches accepted.
Rank-3 query/output head stride equals D. BF16 bk inner page contiguous.
Selected mode uses sel as [M,topk+1], seqused [M], absent cu: one sequence
per query row. General/union mode uses real S-row tables and optional cu;
without cu, M must divide by S. Negative/out-of-range cache pages skipped.
Visible tokens=min(seqused-(query_count)+query_offset+1,4*table_width).
Ascending F32 dot, two-pass max/softmax, double exp rounded F32,
ascending F32 value accumulation and denominator, final BF16 RNE.
No dense replacement above the selection bound is permitted or implemented.

Caller invariants and unsupported cases
Device index contents are not downloaded or validated by shape(). cu must
be monotone/in-range, counts nonnegative/in-range, positions nonnegative
and representable in signed 32-bit arithmetic; no racing duplicate output
pages. Shapes do not prove these device-content invariants.
Unknown params, wrong param kinds, duplicate keys, wrong operand count,
missing required pointers, bad dtype/strides and output overlap are refused.
Explicitly unsupported: other QSA n/ratio/index head counts; topk>512;
other attention D, page sizes, noncausal/windowed attention; external
descale tensors, FP8/quantized queries, non-BF16 block keys, nonzero YaRN.
Shape helpers synthesize benchmark descriptors, not complete model allocation.
Ring7 work/tail APIs are another port; only their existing test dependency
is exercised here. This handoff does not register or modify those APIs.
