attn_paged_gate_had_quant operand order
0 q BF16 [R,3072]; 1 kv_cache I8 [pages,1,4,516];
2 block_table I32 [S,width]; 3 seqused I32 [S];
4 k_descale absent; 5 v_descale absent; 6 cu_seqlens optional I32 [S+1];
7 out BF16 [R,3072]; 8 gate BF16; 9 q8 I8 [R,3072];
10 q8_scale F32 [R,24]. All three outputs are required.
q_len=1..32; 1<=R<=min(2048,q_len_upper*256); 1<=S<=256;
max_seqs=256, max_ctx=1..200000 ADMISSION, causal=1, window=0, group=128,
act=sigmoid, scale absent/default0.0625 or positive finite.
Without cu_seqlens, R must divide into S equal query groups.
When cu_seqlens is absent and S=R, calls strict selected sparse QSA.
Selected width is bounded to 513: topk<=512 COMPLETE pages plus at most
one partial trailing page, not 513 complete selected pages. Caller provides
valid selected seqused<=2051. Wider selected tables return RAD_E_UNSUPPORTED
before enqueue; they NEVER fall through to ordinary/dense attention.
Otherwise calls strict ordinary paged attention, including shared union
tables; width<=50000. This is an explicitly ordinary call, not sparse overflow
fallback. Then calls strict sigmoid gate/BF16 product/Hadamard-I8 quant.
Selected tables can come directly from native QSA selection. Prior GPU4
qualification covered signed-score modes 0/1 at context67 and2052 only.
Packed gate forms: [R,256] row stride>=6144; [R,12,256] head stride512
and row stride>=6144; or [R*12,256] row stride512. Ordinary [R,3072]
pitched and contiguous-head rank3 views are also accepted.

Memory and scratch
Cache pages=1..50000 ADMISSION; exact contiguous strides 2064,2064,516,1.
Each cache token is K[256],V[256],FP16 Kscale,FP16 Vscale, byte516.
Caller supplies valid device contents: positions/table indices/prefix sums,
seqused>=its query-group length, physical page bounds, finite numerical
inputs, and unique nonnegative store slots. No host inspection or sync.
Scratch depends ONLY on declared geometry, not tensors or device data.
Prepare: M_upper*6656*2 bytes, maximum27262976 bytes (26MiB at M2048).
Paged: min(2048,q_len_upper*256)*6144*2, maximum25165824 bytes.
16-byte aligned, full query size required; distinct from every operand.
Range upper bounds drive scratch/capacity; forwarded native params become
concrete integers. Output/output overlaps are rejected before enqueue.
Output/input aliases are staged: tested Qout=q_gate, Kout=K or V,
paged out=Q, with separately allocated quant outputs. Disjointness uses
conservative full-stride envelopes, so arbitrary interleaved output aliases
are not promised. Scratch may be reused on the same stream after completion.
