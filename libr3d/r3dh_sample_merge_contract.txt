No init, scratch, allocation, synchronization, input copies or CPU fallback
in the production entry. Exactly one native HIP block/row on supplied stream.
Full bitonic sort uses 256 threads and 256/512/1024/2048/4096 LDS entries.
Maximum static LDS 49152 bytes. Serial final distinct-pair compaction in block.
Not the sorted-run shortcut in libr4d/libhalo; arbitrary input order accepted.

Runtime limits: declared M=1..8, live rows=1..declared M from output tensor;
n_cand=1..2048; input pairs=1..4096. Rank2 inputs and outputs, inner stride1,
row pitch >= logical width and <= INT32_MAX. Outputs cannot alias any input
or each other. Four-byte alignment, eight-byte params alignment. Params packed
[live_M,24] words (RadSampleParams96); dtype u32/i32/f32 is a raw-byte view.
Gathered u32/i32 [live_M,2*input_pairs]; i32 ids and f32 values [live_M,n_cand].
Actual TP2 n_cand1024 input is [M,4096] WORDS = 2048 candidate pairs.
Optional world_size parameter cross-checks width; not added to canonical schema.
Shape helper declines gathered without explicit world_size: no guessed TP size.

Reference semantics: libref/ref_sample.cpp ref_sample_merge_topk.
Each pair is global token id followed by f32 LOGIT BITS, not numeric conversion.
Signed-negative IDs (including ffffffff) skipped. NaNs skipped, both infinities
eligible. Descending numeric values then lower signed-nonnegative ID. Exact
(numeric-value,id) duplicates emitted once; signed-zero variants compare equal
and preserve earliest input bits. Same ID at a different value remains eligible.
Per-row top_k>0 clamps width; <=0 uses full width. GREEDY emits zero candidates.
Tail is i32 -1 / f32 negative infinity. No token sampled; no softmax or RNG here.
